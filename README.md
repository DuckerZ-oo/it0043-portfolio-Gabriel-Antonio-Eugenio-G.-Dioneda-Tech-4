# Gabriel’s portfolio — Garage & Grounds

A one-page personal portfolio about cars, coffee, music, K-pop, and ducks. The design uses a warm road-trip palette, an original inline SVG illustration, responsive interest cards, and a playlist section.

## Open the page

Open `index.html` in a browser, or use the VS Code Live Server extension. The page has no build step or third-party JavaScript dependencies. Google Fonts load when internet access is available; system sans-serif fallbacks are included.

## Responsive choices

- Flexbox keeps the desktop navigation on one line and lets the small-screen menu stack when opened.
- CSS Grid handles the interest cards and playlist columns.
- Content-led breakpoints at 980px, 720px, and 520px adjust the playlist, hero, cards, and navigation as their available space changes.
- Navigation and buttons have focus and hover feedback. Reduced-motion preferences shorten transitions and turn off smooth scrolling.
